# Dayflow — Smart To-Do List

A polished, responsive To-Do List built with HTML, CSS, and Vanilla JavaScript.

## Features
- Add tasks with a priority and optional due date
- Mark tasks complete or incomplete
- Delete individual tasks and clear all completed tasks
- Filter by all tasks, tasks due today, or completed tasks
- Search by task title
- Sort by recently added, priority, or due date
- Progress ring and remaining-task counts
- Saves tasks in browser localStorage, even after refresh
- Responsive dark design for desktop and mobile

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — task logic, events, filters, and browser storage

## Run in VS Code
1. Extract the ZIP.
2. Open the `dayflow-todo-list-pro` folder in VS Code.
3. Install the **Live Server** extension (optional but recommended).
4. Right-click `index.html` and choose **Open with Live Server**.

No backend, Node.js, database, framework, or paid tools are required.

## Concepts demonstrated
DOM selection, event listeners, `event.preventDefault()`, arrays, `filter()`, `map()`, `sort()`, `createElement()`, and `localStorage`.

## Limitation
Data is saved in the current browser on the current device. It is not synced across users or devices.
